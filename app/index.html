DIO WORKFLOWS / GOOGLE-CONNECTED APPLICATION

DIO
Workflows.

DIO Workflows is a governed media publishing and analytics application used to connect an authorised Google/YouTube account to DIO and NicheFoundry media workflows.

The application helps an authorised operator upload and manage media assets, verify channel and video metadata, read channel/video information and analytics, and preserve an auditable record of requested publishing actions.

Human authority boundary. DIO Workflows does not treat OAuth access as permission for unrestricted autonomous publication. External publishing remains tied to an authorised user or operator action and the permissions granted by the connected account.

What the application does

  • Connects an authorised Google/YouTube account to the DIO media workflow.
  • Uploads user-authorised videos and related media metadata.
  • Supports captions, thumbnails, metadata verification and scheduling where the authorised Google/YouTube API permissions allow those functions.
  • Reads channel and video information needed to confirm the correct channel and verify published media.
  • Reads YouTube Analytics data for controlled reporting and performance measurement.
  • Records technical receipts so the operator can verify which bounded action occurred.

Why Google user data is requested

DIO Workflows requests Google/YouTube access only so the user can connect the intended YouTube channel, publish or manage media they have authorised, verify the resulting channel/video state, and read relevant analytics for that same governed workflow.

The application does not request Google user data for unrelated advertising profiles, sale of personal information, or hidden background publication.

Requested YouTube capabilities

The current media workflow uses Google OAuth permissions for YouTube uploads, YouTube account/channel operations required by the media workflow, read-only YouTube channel/video access, and read-only YouTube Analytics.

Privacy, terms and deletion

Read the DIO Workflows Privacy Policy for details about Google user data access, storage, use and sharing. Use the Data Deletion Instructions to request deletion or disconnection of integration data. Use of DIO Workflows is also subject to the Terms of Service.

Operator and support

DIO Workflows is operated as the DIO Workflows service and product identity. Questions about the application, OAuth permissions or privacy can be sent to dio_workflows@outlook.com.
